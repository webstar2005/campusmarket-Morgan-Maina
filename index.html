Why shop on CampusMarket

Student sellers only

Every listing belongs to a student account, so you always know who you are meeting and which course they are in.

Hand-overs on campus

Agree on the library steps, the hostel gate or the dining hall. No shipping, no courier, no waiting for a parcel.

Honest conditions

Condition is stated on every listing, from brand new to used and fair, so you know what to expect before you walk over.

How this page was built

Every page here is static, on purpose

CampusMarket is currently hand-written HTML and CSS. The server sends this file exactly as it sits in the folder, so every student sees the same catalog. Later in the semester the listings move into MySQL and the pages get generated per request and per student. Same design, one more layer underneath.
