Why shop on CampusMarket

Student sellers only

Every listing belongs to a student account, so you always know who you are meeting and which course they are in.

Hand-overs on campus

Agree on the library steps, the hostel gate or the dining hall. No shipping, no courier, no waiting for a parcel.

Honest conditions

Condition is stated on every listing, from brand new to used and fair, so you know what to expect before you walk over.

How this page behaves

Static files, and a page that reacts

Every page here is hand-written HTML and CSS, and the server sends each file out exactly as it sits in the folder. What changed in Weeks 2 and 3 is what the browser does with them: filters, cart totals and form validation all run on your machine, as you type, and nothing is sent anywhere to make it happen.

That is client-side scripting, and it is for experience rather than safety. Anyone can switch JavaScript off, so from Week 7 the same rules are repeated in PHP against a real database. Same design, a layer underneath it.
