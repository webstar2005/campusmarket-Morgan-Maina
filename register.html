    Right now, nothing. The checks run in your browser and stop there, which is exactly the point the course makes: client-side validation is for experience, not security.

    Someone can turn JavaScript off and post anything they like, so the same rules have to be repeated in PHP once there is a database. That arrives in Week 7.

    Two layers of validation

    The checks on this page are client-side, so they are fast and free. The real safety check is server-side, and it needs a server. This week's version is a rehearsal for that one.
